# MaxyWalk — MAXYWALK Luxury Leather E-Commerce

Premium handcrafted genuine leather footwear (slippers, shoes, mules, sandals) under the registered brand **MAXYWALK**, handcrafted in Avadi, Tamil Nadu, India.

## Features
- 100% Secure Online Payment via Razorpay (UPI, Cards, NetBanking) Pan-India ordering
- Admin Dashboard for inventory management, order tracking, and statistics
- Fully responsive design (Mobile, Tablet, Laptop, Desktop)
- Neon PostgreSQL & Custom Authentication integration

## Stack
- **Frontend**: React 19, Vite, TailwindCSS v4, React Router v7, Zustand, React Hot Toast
- **Database & Auth**: Supabase (PostgreSQL & Auth)
